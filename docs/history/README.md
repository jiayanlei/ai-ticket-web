# 历史留痕文档

这里存放长期有效的项目留痕记录。

## 文件

- `change-log.md`：实现、文档、配置和依赖变更。
- `decision-log.md`：重要产品、架构、依赖和工作流决策。
- `rollback-log.md`：回滚、恢复、hotfix 和还原记录。

## 记录规则

- 使用 `YYYY-MM-DD` 日期。
- 留痕默认使用中文；必要的技术名、产品名、路径、命令、API 名等可以保留原文。
- 条目保持简洁，写清楚范围和验证结果。
- 有相关文件、commit、分支、issue、任务或版本时尽量引用。
- 不删除历史记录。错误修正用新的日期条目补充说明。
