# BI 报表门户 UI 视图细节文档

关联页面：`/analytics/bi`

关联架构文档：`docs/modules/analytics-bi-report-portal-detail.md`

本文档补充 UI 视图、组件层级、尺寸、状态、交互反馈和开发切分细节。目标是让设计和前端可以直接按视图拆组件，不再停留在功能清单层面。

## 1. 总体 UI 原则

BI 报表页采用“传统企业 BI 门户”结构，而不是三栏工作台。页面第一眼要像一个可靠的数据资产入口：能找报表、看状态、进详情、做交付。

视觉基调：

- 沿用 AI Ticket OS 管理台风格：深色企业运营界面、信息密度高、状态清楚。
- 卡片只用于摘要、快捷入口和报表推荐，核心资产区使用表格。
- 报表详情页使用“工作簿页签”，接近 Tableau、Power BI、FineBI 这类传统 BI 使用习惯。
- 页面不做营销式 hero，不做大面积装饰图，不做三栏堆叠。

核心布局：

```text
页面容器
├─ 顶部工具栏
├─ 资产健康概览
├─ 快捷入口区
├─ 报表资产区
│  ├─ 分类 Tabs + 视图切换 + 批量操作
│  └─ 报表表格 / 报表卡片视图
└─ 弹层
   ├─ 报表详情
   ├─ 订阅配置
   ├─ 导出队列
   ├─ 指标口径
   └─ 口径冲突处理
```

## 2. 桌面端视图尺寸

优先适配企业后台常见桌面分辨率。

| 视口 | 布局策略 |
| --- | --- |
| 1920 x 1080 | 标准全量布局，健康指标 6 列，快捷入口 5 列，表格完整展示 |
| 1440 x 900 | 健康指标 6 列，快捷入口 5 列，表格操作列折叠更多 |
| 1366 x 768 | 工具栏换行，快捷入口压缩高度，表格保留核心列 |
| 小于 1280 | 仍按桌面后台处理，页面可横向最小宽度保护 |

建议容器：

| 区域 | 尺寸建议 |
| --- | --- |
| 页面内边距 | 16px |
| 区块间距 | 16px |
| 顶部工具栏高度 | 72px 至 88px |
| 健康指标卡高度 | 86px |
| 快捷入口卡高度 | 116px 至 136px |
| 报表列表区最小高度 | `calc(100vh - 360px)` |
| 卡片圆角 | 8px |
| 表格行高 | 48px |

### 3.2 顶部工具栏 UI

结构：

- 第一行：页面标题、页面说明、右侧主操作。
- 第二行：搜索和筛选条件。
- 如果当前系统页面标题已由布局提供，可在页面内部只保留工具栏和说明。

控件规格：

| 控件 | UI 细节 |
| --- | --- |
| 页面标题 | 20px 至 22px，600 字重 |
| 描述文案 | 13px 至 14px，弱文本色，一行内展示 |
| 搜索框 | 宽 280px 至 360px，带搜索图标，支持清除 |
| 日期范围 | 宽 220px，默认“最近 30 天” |
| 业务域 | 宽 120px |
| 状态 | 宽 120px |
| 负责人 | 宽 140px |
| 查询按钮 | 主按钮 |
| 重置按钮 | 次按钮 |
| 新建报表 | 主按钮，放在右侧操作区 |
| 导出中心 / 订阅中心 | 普通按钮或图标按钮 + tooltip |

交互状态：

- 查询中：查询按钮 loading，表格和指标区局部 loading。
- 有筛选条件：筛选栏下方展示已选条件标签，可一键清除。
- 筛选过多：标签区域最多显示一行，溢出显示“+N”。

### 3.3 资产健康概览 UI

六张横向指标卡：

```text
[报表总数] [活跃报表] [订阅任务] [导出请求] [口径冲突] [数据新鲜度]
```

单卡结构：

```text
┌────────────────────┐
│ 报表总数        图标 │
│ 128                │
│ 较上周 +4.2%        │
└────────────────────┘
```

字段层级：

| 元素 | 规格 |
| --- | --- |
| 标签 | 12px，弱文本 |
| 主数值 | 26px 至 32px，600 至 700 字重 |
| 趋势 | 12px，带颜色和箭头 |
| 图标 | 18px 至 20px，低饱和强调色 |

状态颜色：

| 类型 | 颜色语义 |
| --- | --- |
| 正常增长 | 绿色 |
| 中性变化 | 蓝色 / 青色 |
| 需要关注 | 琥珀色 |
| 失败或冲突 | 红色 |

点击行为：

- 点击“口径冲突”打开口径冲突列表。
- 点击“导出请求”打开导出任务队列。
- 点击“订阅任务”打开订阅中心。
- 点击“数据新鲜度”筛选刷新异常报表。

### 3.4 快捷入口区 UI

推荐使用横向 5 组小卡，而不是三栏。

```text
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 推荐报表      │ │ 最近使用      │ │ 我收藏的      │ │ 我负责的      │ │ 异常报表      │
│ SLA履约周报   │ │ 运营日报      │ │ 客服效率看板  │ │ 渠道成本分析  │ │ 订阅失败 3    │
│ 可信度 96     │ │ 12分钟前      │ │ 已收藏 8      │ │ 待发布 2      │ │ 立即处理      │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

每组卡片可包含 1 个主报表和 2 条轻量链接。

组件细节：

| 元素 | 说明 |
| --- | --- |
| 卡片标题 | 推荐报表、最近使用等 |
| 主报表名称 | 最多两行，超出省略 |
| 标签 | 业务域、状态、可信度 |
| 辅助信息 | 最近刷新、使用次数、异常原因 |
| 操作 | 打开、查看全部 |

异常报表卡特殊规则：

- 有异常时置于第五张，使用警示边框。
- 展示最高优先级异常，例如“数据集刷新失败”“订阅发送失败”“指标口径冲突”。
- 点击主卡进入异常列表，点击报表名进入报表详情。


- 数据新鲜度：40%

- 卡片包含名称、业务域、负责人、可信度、最近刷新、状态、打开按钮。
- 异常卡片需要显示异常原因。

### 4.2 详情头部 UI

详情头部要把“这张报表是否能信”讲清楚。

字段：

| 区域 | 内容 |
| --- | --- |
| 主标题 | 报表名称 |
| 标签 | 状态、业务域、是否收藏 |
| 可信度 | 分数 + tooltip |
| 刷新状态 | 最近刷新时间、下次刷新时间 |

- 查看权限
- 复制报表
- 查看发布历史
- 查看审计日志
- 下线报表

### 4.3 详情页签 UI

页签保持一行，过多时使用更多菜单。

| 页签 | UI 内容 |
| --- | --- |
| 总览 | KPI、趋势、AI 摘要、核心明细 |
| 趋势分析 | 多指标趋势图、异常点列表、同比环比 |
| 渠道分布 | 渠道占比、渠道趋势、渠道明细排行 |
| 坐席绩效 | 团队榜单、个人表现、技能组对比 |
| SLA 明细 | SLA 达成、超时原因、补救动作、明细表 |
| 数据血缘 | 数据集、字段、指标引用、刷新链路 |
| 订阅记录 | 订阅任务、接收人、发送结果、失败重试 |

切换规则：

- 页签切换不丢失全局筛选。
- 每个页签可有自己的局部筛选。
- 切换页签时图表局部 loading，不刷新整个详情页。

### 4.4 筛选条 UI

详情页筛选条采用紧凑单行，支持展开高级筛选。

默认展示：

```text
[最近30天] [租户] [渠道] [团队] [SLA状态] [保存视图] [重置]
```

展开高级筛选：

```text
客户等级 / 工单类型 / 优先级 / 坐席 / 区域 / 标签 / 创建来源
```

保存视图流程：

```mermaid
flowchart LR
  A["调整筛选条件"] --> B["点击保存视图"]
  B --> C["输入视图名称"]
  C --> D["选择仅自己可见或团队可见"]
  D --> E["保存成功"]
  E --> F["门户快捷入口出现该视图"]
```

```text

│                              │
│ ECharts 图表区域              │
│                              │
│ 图例 / 最近更新时间            │
└──────────────────────────────┘
```

图表操作菜单：

- 查看数据
- 下载图片
- 导出当前数据
- 查看指标口径
- 加入订阅

- 不允许只有空白图框。
- 无数据时展示原因：筛选条件无结果、数据集未刷新、无权限。
- 提供“重置筛选”或“查看数据集状态”。

## 5. 弹层视图细节

### 5.1 新建报表向导

呈现方式：居中大弹窗或全屏向导。

建议宽度：960px 至 1120px。

步骤条：

```text
1 选择模板 -> 2 选择数据集 -> 3 配置指标 -> 4 配置图表 -> 5 权限订阅 -> 6 预览发布
```

每步 UI：

| 步骤 | 视图细节 |
| --- | --- |
| 选择模板 | 模板卡片网格，包含空白报表、运营日报、SLA、坐席绩效、风险分析 |
| 选择数据集 | 数据集表格，展示名称、刷新频率、字段数、负责人、新鲜度 |
| 配置指标 | 左侧指标选择，右侧已选指标列表，底部展示口径说明 |
| 配置图表 | 图表类型卡片 + 简单布局预览 |
| 权限订阅 | 可见范围、协作者、默认订阅、发送频率 |
| 预览发布 | 报表预览、发布说明、校验结果 |

底部按钮：

- 上一步
- 下一步
- 保存草稿
- 发布

### 5.2 订阅配置弹窗

宽度：720px。

布局：

```text
订阅配置
├─ 基本信息：订阅名称、报表、筛选视图
├─ 接收范围：用户、角色、部门
├─ 发送规则：频率、时间、时区、节假日策略
├─ 文件设置：PDF / Excel / CSV、是否压缩
└─ 失败处理：通知负责人、自动重试
```

关键交互：

- 选择“固定当前筛选”时，展示当前筛选条件摘要。
- 选择接收人后，展示预计接收人数。
- 保存后显示“下次发送时间”。

### 5.3 导出中心

呈现方式：抽屉或弹窗，推荐抽屉宽度 860px。

视图：

```text
导出中心
├─ 顶部筛选：状态、格式、发起人、时间
├─ 任务列表
│  ├─ 排队中
│  ├─ 生成中
│  ├─ 已完成
│  └─ 失败
└─ 底部说明：文件保留时间、权限提示
```

任务状态 UI：

| 状态 | 表现 |
| --- | --- |
| 排队中 | 灰色进度 |
| 生成中 | 蓝色进度条 |
| 已完成 | 绿色标签 + 下载按钮 |
| 失败 | 红色标签 + 查看错误 + 重试 |

### 5.4 指标口径详情抽屉

宽度：720px。

结构：

```text
指标口径
├─ 指标名称 + 状态
├─ 业务定义
├─ 计算公式
├─ 数据来源
├─ 引用报表
├─ 变更历史
└─ 治理动作
```

公式展示：

```text
首次响应率 = 首次响应在 SLA 内的工单数 / 需首次响应的工单数
过滤条件：已删除工单、测试租户、机器人纯自动会话不计入
```

治理动作：

- 申请变更
- 设为标准口径
- 查看冲突
- 通知引用报表负责人

### 5.5 口径冲突处理视图

呈现方式：大抽屉或独立弹窗，宽度 960px。

视图结构：

```text
口径冲突处理
├─ 冲突摘要：冲突指标、影响报表数、严重程度
├─ 对比表：指标 A vs 指标 B
├─ 影响分析：引用报表、订阅任务、负责人
├─ 处理方案：选择标准口径 / 合并 / 暂不处理
└─ 提交审批
```

对比表字段：

| 对比项 | 指标 A | 指标 B |
| --- | --- | --- |
| 指标名称 | 首次响应率 | 首响达成率 |
| 公式 | A / B | C / D |
| 数据源 | ticket_sla | ticket_response |
| 引用报表 | 12 | 8 |
| 负责人 | 陈沐阳 | 谢砚青 |

## 7. 组件状态细节

### 7.1 按钮状态

| 操作 | 正常 | 禁用条件 |
| --- | --- | --- |
| 新建报表 | 可点击 | 无 `analytics:bi:create` 权限 |
| 打开 | 可点击 | 报表已下线且无查看历史权限 |
| 编辑 | 可点击 | 非负责人且无编辑权限 |
| 订阅 | 可点击 | 报表草稿、报表异常、无订阅权限 |
| 导出 | 可点击 | 无导出权限、数据未刷新 |
| 发布 | 可点击 | 校验未通过、无发布权限 |

### 7.2 表格行状态

| 状态 | 行样式 |
| --- | --- |
| 正常 | 默认背景 |
| 异常 | 左侧 3px 警示色或状态标签高亮 |
| 草稿 | 状态弱化，操作以编辑为主 |
| 已下线 | 整行弱化，操作收敛为查看历史 |
| 选中 | 背景强调，批量操作栏出现 |

### 7.3 加载与骨架屏

加载顺序：

1. 顶部工具栏立即显示。
2. 健康指标显示骨架。
3. 快捷入口显示骨架卡。
4. 表格显示骨架行。

局部刷新：

- 查询筛选只刷新指标、快捷入口和表格。
- 打开详情只刷新详情内容。
- 切换详情页签只刷新当前页签图表。
