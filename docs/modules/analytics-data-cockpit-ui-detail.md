# 数据驾驶舱 UI 细节文档

## 1. 页面目标

- 路由：`/analytics/cockpit`
- 页面名称：数据驾驶舱
- 页面目标：用轻量运营控制台完成“看健康、抓风险、派动作、验恢复”。
- 设计原则：避免大量卡片化表达，主体使用指标带、工作列表、行动队列、抽屉和时间线。

核心闭环：

```text
健康总览发现异常 -> 风险工作列表定位证据 -> 闭环行动派发处理 -> 验证恢复 -> 关闭或回流风险
```

布局约束：

- 顶部控制区固定为一行，承载范围筛选和关键动作。
- 健康总览使用一条横向指标带，不使用 5 个大卡片。
- 风险指挥使用工作列表作为主体，最多保留一行摘要，不做风险卡片墙。
- 闭环行动使用状态队列和紧凑列表，不做行动卡片网格。
- 页面最小宽度沿用当前后台工作台风格，建议 `1180px` 以上。

## 3. 视觉与交互原则

### 推荐形态

- 指标带：用于首屏快速判断，强调数值、变化和影响维度。
- 表格/列表：用于风险和行动，便于扫描、排序、筛选。
- 状态条：用于待派发、处理中、待验证、已关闭。
- 抽屉：用于详情、证据、时间线和创建行动。
- 标签：用于优先级、风险类型、负责人状态。

### 避免形态

- 大量独立卡片。
- 卡片嵌套卡片。
- “AI 洞察卡”“智能建议卡”等孤立装饰模块。
- 过多渐变、发光边框、装饰图形。
- 首屏堆多个图表面板。

### 卡片使用边界

- 可以使用紧凑信息单元，但不称为主卡片。
- 单屏可见的独立块数量应控制在 3 个以内。
- 信息单元圆角保持 8px 或更小，阴影弱化。
- 风险和行动主体必须优先使用表格行或列表行。

## 4. 顶部控制区

### 展示内容

- 页面标题：数据驾驶舱
- 更新时间：例如 `更新于 22:13`
- 时间范围：今日 / 近 7 天 / 近 30 天 / 自定义
- 渠道筛选：全部、电话、在线、邮件、短信、统一收件箱
- 团队筛选：全部、华东客服、华南客服、技术支持、VIP 支持
- 操作按钮：刷新、进入大屏

### 交互

- 切换时间、渠道、团队后，指标带、风险列表、行动队列同步刷新。
- 点击刷新时显示按钮 loading，并更新页面时间戳。
- 点击进入大屏，跳转或打开 `/dashboard/screen`，保留当前筛选上下文。

## 5. 区块一：健康总览

### 业务作用

回答“今天整体是否正常，异常优先看哪里”。

### 指标带

| 指标 | 示例值 | 状态规则 | 点击后行为 |
| --- | --- | --- | --- |
| 综合健康分 | 88 | `< 70` 红色，`70-84` 橙色，`>= 85` 绿色 | 筛选全部异常风险 |
| 今日服务量 | 12.8k | 环比突增超过 15% 标橙 | 筛选服务压力风险 |
| SLA 达成率 | 91.6% | 低于 90% 标红 | 筛选 SLA 风险 |
| 队列压力 | 72 | 高于 80 标红 | 筛选服务压力风险 |
| AI ROI | +8.4% | 低于 0 标橙，失败率升高标红 | 筛选 AI 质量风险 |

### 单个指标单元

```text
SLA 达成率  91.6%  ↓4.2%  影响: 在线渠道  风险: 18
```

### 状态

- 正常：文本和细分隔线为中性色，数字突出。
- 预警：趋势值和左侧状态点用橙色。
- 严重：趋势值和左侧状态点用红色，并显示 `需处理` 标签。
- 空数据：显示 `暂无数据`，筛选动作禁用。
- 加载中：使用横向骨架条，不出现空白图表。

## 6. 区块二：风险指挥

### 业务作用

回答“哪里出了问题、证据是什么、下一步应该去哪处理”。

### 风险分类

只保留 3 个分组：

- SLA 风险：即将超时、已经超时、重点客户超时。
- 服务压力风险：队列积压、坐席负载过高、排班缺口。
- AI 质量风险：AI 自动处理失败、转人工率上升、知识命中下降。

### 风险工作列表

```text
优先级 | 风险对象       | 影响指标                 | 证据                         | 建议动作           | 入口
高     | 重点客户 SLA   | SLA -4.2%，18 单将超时   | 在线 / 华东 / 投诉 / 14-16点  | 升级工单，加派坐席 | 工单 SLA
中     | 在线渠道积压   | 积压 +136，等待 +6分钟   | 华东 / 技术支持 / 32 会话     | 临时调班           | 排班 监控
高     | AI 处理失败    | 转人工 +18%，命中 -9%    | 知识缺口 / 模型调用失败 23次  | 补知识，切模型策略 | 知识 模型
```

### 字段

| 字段 | 说明 |
| --- | --- |
| 优先级 | 紧急 / 高 / 中 |
| 风险对象 | 客户、渠道、团队或业务类型 |
| 影响指标 | 说明指标变化和业务影响 |
| 证据 | 渠道、团队、时段、业务类型、关联数量 |
| 建议动作 | 可执行动作，不写空泛提醒 |
| 行动状态 | 未派发 / 已派发 / 处理中 / 待验证 |
| 入口 | 跳转到工单、SLA、风险、监控、AI 模型等模块 |

### 交互

- 点击指标带后，风险列表按关联类型筛选。
- 点击风险行打开风险详情抽屉。
- 点击关联入口跳转对应模块。
- 点击 `创建行动`，将风险带入闭环行动区。
- 已创建行动的风险行显示行动状态，避免重复派发。

### 风险详情抽屉

抽屉内容：

- 风险摘要
- 影响指标
- 根因证据表
- 关联记录：工单、客户、坐席、知识、模型调用
- 建议动作
- 已有关联行动
- 处理时间线
- 按钮：创建行动、进入关联模块、标记已知问题

## 7. 区块三：闭环行动

### 业务作用

回答“谁负责、做什么、进展如何、指标有没有恢复”。

### 状态流

```text
待派发 -> 处理中 -> 待验证 -> 已关闭
```

### 行动队列

```text
状态   | 处理动作             | 来源风险       | 负责人 | 截止时间   | 进度 | 验证指标
处理   | 临时加派技术支持坐席 | 重点客户 SLA   | 陈沐阳 | 今天18:00 | 60%  | SLA >= 90%
验证   | 补充投诉类知识条目   | AI 处理失败    | 韩书   | 今天19:00 | 90%  | 命中率 >= 82%
待派发 | 调整华东在线班次     | 在线渠道积压   | -      | 今天17:30 | 0%   | 积压 < 80
```

### 字段

| 字段 | 说明 |
| --- | --- |
| 来源风险 | 从哪条风险创建 |
| 处理动作 | 具体可执行动作 |
| 负责人 | 行动责任人 |
| 截止时间 | 处理时限 |
| 当前状态 | 待派发 / 处理中 / 待验证 / 已关闭 |
| 进度 | 0-100% |
| 验证指标 | 用什么指标判断是否恢复 |
| 关闭证据 | 指标恢复、处理记录、复盘说明 |

### 创建行动弹窗

字段：

- 来源风险：默认带入，不可编辑或弱编辑。
- 处理动作：默认填入建议动作，可修改。
- 负责人：下拉选择。
- 截止时间：日期时间选择。
- 验证指标：默认基于风险类型生成。
- 说明：可选。

### 验证规则

- 未设置负责人不能进入处理中。
- 未设置验证指标不能进入待验证。
- 进入 `待验证` 后，对比行动创建前后的关键指标。
- 已恢复：允许关闭，要求填写关闭说明。
- 未恢复：不允许关闭，行动回到处理中，风险重新进入风险列表。

## 8. 页面状态

### 加载态

- 指标带显示横向骨架条。
- 风险列表显示表格骨架行。
- 行动队列显示列表骨架行。

### 空状态

- 无风险：风险列表显示“当前暂无高优风险”，并保留最近已关闭行动入口。
- 无行动：行动队列显示“暂无待处理行动”，提供从风险创建行动的提示。

### 错误态

- 数据加载失败：顶部显示错误提示，保留重试按钮。
- 关联模块跳转失败：message 提示“入口暂不可用”。

### 权限态

- 无查看权限：显示无权限页。
- 无创建行动权限：隐藏创建行动按钮，只保留查看和跳转。
- 无大屏权限：隐藏进入大屏按钮。

## 10. 组件拆分建议

- `CockpitToolbar`：顶部筛选和动作。
- `HealthOverviewStrip`：横向指标带。
- `HealthMetricItem`：单个指标单元。
- `RiskCommandPanel`：风险筛选、分组和工作列表。
- `RiskWorklist`：风险表格或列表行。
- `RiskDetailDrawer`：风险详情、证据、时间线和创建行动入口。
- `ClosedLoopActionPanel`：行动状态汇总和行动队列。
- `ActionQueue`：行动表格或列表行。
- `CreateActionModal`：创建行动弹窗。

## 11. 第一期验收标准

- 首屏只保留健康总览、风险指挥、闭环行动 3 个主区块。
- 页面主体不是卡片墙，风险和行动必须以工作列表/队列表达。
- 指标带有明确状态和异常筛选能力。
- 风险只保留 SLA、服务压力、AI 质量 3 类。
- 每条风险必须有影响指标、根因证据、建议动作、行动状态和关联入口。
- 可以从风险创建行动。
- 行动必须有负责人、截止时间、状态、进度和验证指标。
- 行动关闭前必须完成恢复验证或填写复盘说明。
- 页面不能出现空白图表面板。
