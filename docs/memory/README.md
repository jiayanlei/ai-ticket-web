# 项目记忆

这里存放项目的浅层工作记忆，用于下次对话快速恢复上下文。

- `project.md`：项目介绍和当前状态。
- `notes.md`：有价值的历史上下文和补充说明。
- `todos.md`：未完成事项和后续动作。
- `decisions.md`：已经确认的关键决策。
- `cautions.md`：约束、坑点和重要注意事项。
- `rollbacks.md`：回滚、恢复和风险处理记录。
- `sessions-YYYY-MM.md`：按月汇总的会话摘要。

留痕默认使用中文。必要的技术名、产品名、路径、命令、字段名、组件名、API 名和模块名可以保留原文。不要记录完整聊天原文、密钥、Token、凭证、个人敏感信息或大段日志。
